### <img src="https://img.shields.io/badge/%E2%97%8F-4ECDC4?style=flat-square" alt=""/> ComplianceMate
**Food-safety compliance SaaS**

Full-stack and platform engineering on a Rails application for regulated food-safety compliance — connected kitchen tablets, temperature-sensor telemetry, real-time alerting, and audit-grade reporting. Work spans device-fleet management, the reporting engine, async IoT messaging pipelines, and a ground-up dashboard redesign on Rails 7.2 with Hotwire. The domain rewards correctness: timezone-accurate data and reports that have to be exactly right.
